# WeStudy-Portfolio

**Live Demo:** [WeStudy Web Portal](https://tutor-terminal-api.onrender.com/) *(Note: The free Render server may take 50 seconds to wake up on the first load).*

## 📖 Concept
WeStudy is a full-stack academic productivity dashboard that unifies course tracking, GPA calculation, and AI-powered study tools with an autonomous WhatsApp assistant for real-time exam and schedule management.

## ✨ Key Features
* **Smart Calendar & Tasks:** Track upcoming exams, calculate dynamic GPAs, and manage daily to-dos.
* **Nova AI Assistant (Google Gemini):** Generate instant study flashcards from lecture notes and chat with an AI study buddy directly in the app.
* **WhatsApp Integration (Twilio):** Text Nova on WhatsApp to automatically log calendar events and sync them with your dashboard in real-time.
* **Productivity Timers:** Built-in Pomodoro timers, stopwatches, and desktop study alarms.

## 🛠️ Tech Stack
* **Frontend:** Flutter Web (Dart), SharedPreferences
* **Backend:** FastAPI (Python), SQLAlchemy
* **Database:** PostgreSQL (Neon Serverless)
* **AI & Integrations:** Google Gemini 2.5 Flash, Twilio Webhooks
* **Deployment:** Render
